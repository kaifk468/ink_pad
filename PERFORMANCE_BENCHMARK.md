# InkPad synthetic render benchmark

Run `npm run dev`, open InkPad, and open **Perf**. Choose **Run controlled** to compare equivalent logical render conditions, or **Run native** to measure the device's current browser/canvas environment. Each run measures the 25, 250, and 1,000 item scenes with Blank, Lined, and Dotted templates, white sheet color, the same deterministic seed, 8 warm-up frames, and 40 measured frames per scenario. The same generator and composition are used in both modes.

Controlled mode temporarily sets the main canvas backing store to 1200×800 at effective DPR 1 and renders at zoom 1 with zero offsets. It does not resize the browser viewport or persist/change the app viewport. The app's canvas backing dimensions and scene refs are restored after the run. Native mode leaves canvas backing dimensions, device DPR, zoom, and offsets unchanged. Both modes temporarily disable pointer input on the drawing canvas while benchmark scenes are rendered.

Choose **Export benchmark JSON** after a run. Schema version 2 includes top-level benchmark mode and device/browser metadata. Each scenario records mode, template, sheet color, actual and configured browser viewport dimensions, actual/effective DPR, actual/effective canvas backing dimensions, canvas zoom and offsets, seed, object composition, point count, warm-up/measured frames, and median/P95/max/counts for background fill/template, total render, historical ink, active stroke, RAF gaps, compositing, minimap, page overview, and Long Animation Frames if supported. Controlled and Native runs produce separate files/results; compare only runs with the same mode when evaluating rendering performance.

For repeatability, keep the same browser/app build and avoid interacting during capture. Controlled mode normalizes logical main-canvas raster conditions for cross-device comparison; it does not make GPUs, browsers, operating systems, or compositors identical. Native mode represents each device's actual environment. Neither browser timing measures digitizer-to-photon latency; confirm S Pen responsiveness on the Galaxy Tab S9 FE+ separately. No production caching or rendering optimization is applied by this benchmark.

Since the CSS sheet layer change (2026-10-31), the main canvas no longer paints the sheet color or template. `backgroundRenderMs` therefore measures only the style update of the sheet layer (near zero) and no longer includes pattern painting; any paint or compositing cost of the layer appears in `frameGapMs` and Long Animation Frames instead. Compare Lined and Dotted against Blank on those two metrics, and do not compare `backgroundRenderMs` with captures taken before this change.
